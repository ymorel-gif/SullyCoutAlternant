# Mots 888

Application de révision de vocabulaire, mobile, 100 % locale (aucun serveur, aucun compte).
La progression est stockée dans le navigateur du téléphone (localStorage / IndexedDB).

- Ouvrir `index.html` (ou l'URL GitHub Pages) sur le téléphone, puis « Ajouter à l'écran d'accueil ».
- Mettre à jour les mots : Google Sheets › Fichier › Télécharger › CSV, puis Réglages › Importer un CSV.
- Méthode : rappel actif + répétition espacée (Leitner) + alternance des types de questions.
